# 产品边界

## 当前主工程

`family-companion-platform` 是家庭陪伴平台 Web 主工程。

当前优先完成 Web 平台基础能力和健康数据闭环：

- Supabase Auth
- 家庭管理
- 协作成员管理
- 健康档案管理
- 血压记录
- 用药记录
- 提醒事项
- 异常记录
- 周报/月报
- 工作台统计

## 当前不做

当前阶段不做小程序接入，也不把小程序能力直接迁入 Web 主工程。

暂不做：

- 吾伴 AI 小程序对接
- 小安小程序对接
- 小程序登录体系整合
- 小程序数据同步 API
- 小程序端页面重构
- AI 健康总结
- 复杂 AI 陪伴能力
- 主动提醒推送调度
- 智能硬件对接

## 小程序定位

两个小程序先独立运行。

- 吾伴 AI 小程序：学生端，当前定位为作业练习扫描上传和分析。
- 小安小程序：家人端/长辈端，后续作为家庭成员侧数据入口。

等 Web 平台完成并稳定后，再把小程序作为数据入口接入平台。

## 后续接入原则

后续对接小程序时，Web 平台仍作为统一账户、家庭、健康档案、健康数据和 AI 服务中心。

小程序只负责采集或展示特定场景的数据，不作为平台主架构。
