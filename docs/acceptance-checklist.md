# 人工验收清单

## 验收前置

- 已执行 `pnpm db:migrate`
- 已执行 `pnpm verify:build`
- 线上或本地 `/api/health` 返回 `ok: true` 和 `status: "ready"`
- `currentPhaseGuards` 中所有项目均为 `ok: true`
- Supabase Auth 已开启 Email 登录
- `SUPABASE_SERVICE_ROLE_KEY` 已配置，用于服务端创建手机号账号

## 账户流程

1. 打开 `/register`，使用中国大陆手机号和密码注册一个新账号。
2. 注册成功后应进入 `/dashboard`。
3. 退出登录后打开 `/login`，再次使用手机号和密码登录，并确认进入 `/dashboard`。
4. 打开 `/profile`，填写或修改显示名称和手机号，退出后确认可用新手机号登录。
5. 在 `/profile` 修改密码，退出后用新密码重新登录。

## 家庭与成员

1. 打开 `/families/new`，创建一个家庭。
2. 打开家庭详情页，确认核心内容是家庭成员列表，不显示协作成员数量和健康档案数量统计卡。
3. 新增家庭成员，填写姓名、称谓/关系、性别、生日、电话、紧急联系人、地址和医疗备注。
4. 确认家庭成员卡片显示关系、年龄、最近血压、未解决异常，并提供健康档案、健康数据、用药记录、异常记录和编辑入口。
5. 打开协作成员页，邀请一个手机号。
6. 使用匹配手机号的第二个账号登录，打开 `/invitations` 接受邀请。
7. 回到第一个账号，确认协作成员列表出现新账号。
8. 调整协作成员角色，确认 owner/admin 权限限制符合预期。

## 健康档案

1. 从家庭成员卡片进入健康档案。
2. 确认健康档案只展示该成员自己的血压、用药、提醒、异常和报告入口。
3. 编辑家庭成员并保存，确认家庭详情页和健康档案详情页同步更新。

## 血压记录

1. 打开健康档案下的血压页面。
2. 新增一条正常血压记录，确认列表、统计卡片和趋势图更新。
3. 新增一条高血压记录，确认自动生成异常记录。
4. 编辑血压记录，确认数值和时间显示正确。
5. 删除血压记录，确认列表更新。
6. 导出明细表，确认文件能下载且内容正确。
7. 导出月历版，确认打开后是按星期排列的月历格式，早/中/晚记录在对应日期格内。
8. 导入 CSV 或 Excel，确认成功条数、失败条数和异常记录数量提示正确。
9. 上传血压照片，确认图片能保存并可查看签名链接。
10. 如果配置了 `COZE_WORKLOAD_IDENTITY_API_KEY`，测试 OCR 识别；未配置时确认页面提示 OCR 不可用。

## 用药、提醒、异常

1. 新增用药记录，填写药名、剂量、频次、说明和备注。
2. 调整用药状态，确认状态更新。
3. 新增提醒事项，填写标题、类型、计划时间、重复说明和备注。
4. 调整提醒状态，确认状态更新。
5. 新增异常记录，填写类型、严重程度、发生时间和描述。
6. 调整异常状态，确认状态更新。
7. 删除用药、提醒、异常记录，确认删除中状态和列表刷新正常。

## 健康报告

1. 打开报告页，生成周报。
2. 再生成同周期周报，应提示该周期报告已存在。
3. 生成月报，确认统计摘要包含血压、用药、提醒和异常数据。
4. 下载 Markdown，确认文件内容包含健康档案成员、周期、统计和生成时间。
5. 删除报告，确认删除中状态和列表刷新正常。

## 工作台

1. 打开 `/dashboard`。
2. 确认只显示家庭级统计：家庭数量、家庭成员数量、协作成员数量、待处理提醒数量。
3. 确认工作台不混合展示多个成员的血压、用药、异常和健康报告统计。
4. 确认具体健康数据必须从家庭详情页进入某个家庭成员后查看。
